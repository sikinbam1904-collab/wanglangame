# วังหลัง — ชะตารักเหนือบัลลังก์

เกม visual novel ภาษาไทยแนวจีนโบราณ/วังหลัง เล่นผ่านเว็บเบราว์เซอร์ได้โดยไม่ต้องติดตั้งเครื่องมือ build

## วิธีเล่นในเครื่อง
1. ดาวน์โหลดหรือแตกไฟล์ ZIP
2. เปิด `index.html` ด้วยเบราว์เซอร์
3. เลือกภูมิหลัง ตั้งชื่อตัวละคร และเล่นให้ครบ 10 ตอน
4. ความคืบหน้าจะบันทึกใน `localStorage` ของเบราว์เซอร์เดียวกัน

## วิธีนำขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลด `index.html`, `style.css`, `game.js` และโฟลเดอร์ `assets` ไปไว้ที่ root ของ repository
3. เข้า **Settings → Pages**
4. เลือก **Deploy from a branch**, เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
5. รอ GitHub สร้างเว็บไซต์ แล้วเปิด URL ที่แสดงในหน้า Pages

## คุณสมบัติ
- 10 ตอนพร้อมตัวเลือกที่เปลี่ยนค่าความสัมพันธ์และค่าสถานะ
- ภูมิหลังตัวละคร 4 แบบ
- ค่าสถานะ: ความรัก อำนาจ สติปัญญา ความแค้น ความไว้วางใจ และความลับ
- บทสรุป 8 แบบ เลือกตามคะแนนเมื่อเล่นจบ
- รองรับหน้าจอมือถือและแท็บเล็ต
- บันทึกความคืบหน้าในเบราว์เซอร์
- ไม่ต้องมี API key หรือ backend

## หมายเหตุ
ภาพฉากในเวอร์ชันนี้เป็นภาพประกอบที่สร้างด้วย CSS เพื่อให้โหลดไวและใช้งานได้ทันที โฟลเดอร์ `assets` อาจมีภาพ concept art สำหรับอ้างอิงการออกแบบเพิ่มเติม ภาพประกอบ/ข้อความในเกมสามารถเปลี่ยนหรือเพิ่มได้ภายหลัง

ฟอนต์จาก Google Fonts จะโหลดเมื่อมีอินเทอร์เน็ต หากออฟไลน์ เว็บไซต์ยังใช้งานได้ด้วยฟอนต์สำรองของระบบ
